发票工具箱使用说明

发票工具箱是一款 Windows 桌面软件，适合财务报销、项目归档和批量整理发票。它把扫描、核对、查重、导出和归档放进同一套流程，减少重复打开文件和手工登记的时间。

基本使用步骤

  1. 下载并安装发票工具箱，打开需要整理的项目文件夹。
  2. 批量扫描发票文件，查看自动识别出的号码、金额和日期等字段。
  3. 重点核对待确认项和重复项，必要时手动修正。
  4. 选择需要的字段和顺序，导出 Excel 或完成归档。

适用场景

  • 月度报销发票集中登记与核对。
  • 按项目批量整理、查重和归档发票。
  • 将发票关键信息汇总为可编辑的 Excel 表格。

常见问题

这款软件支持什么系统？

当前提供 Windows 桌面版本，具体版本和发布日期可在本页“当前版本”中查看。

识别后还需要人工检查吗？

建议检查软件标出的待确认项和重复项，尤其是金额、发票号码及日期，确认无误后再导出或归档。

可以直接导出 Excel 吗？

可以。导出前还可以选择字段，并调整 Excel 列的排列顺序。
