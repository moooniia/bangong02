PDF 转图片使用说明

把 PDF 每一页转换为 PNG 图片并打包下载，适合制作预览图、分享页面或提取整页画面。

使用步骤

  1. 选择需要转换的 PDF
  2. 开始逐页转换
  3. 等待系统打包
  4. 下载 ZIP 并检查页码

使用建议

  • 页数多时文件会较大
  • 需要小体积可继续压缩图片
  • 转换结果是整页画面
  • 请按页码顺序使用图片

常见问题

和提取 PDF 图片有什么区别？

PDF 转图片会把整页渲染成图片；提取图片只导出 PDF 内嵌的独立图像资源。

可以选择 JPG 吗？

当前页面按提示输出固定格式，如需其他格式可再使用图片格式转换。

上传的文件会长期保留吗？

不会。文件仅用于本次处理，完成后会按网站规则自动删除。
