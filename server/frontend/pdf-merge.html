合并 PDF 使用说明

把多份 PDF 按上传顺序整理成一个文件，适合汇总合同附件、扫描资料、报告章节和报销凭证。合并只改变文件组合顺序，不会主动修改页面内容。

使用步骤

  1. 一次选择多份 PDF 文件。
  2. 确认文件列表和排列顺序。
  3. 点击开始合并并等待处理。
  4. 下载合并后的完整 PDF。

合并前建议

  • 先按阅读顺序整理文件名
  • 确认每份文件都能正常打开
  • 体积较大时先进行 PDF 压缩
  • 敏感资料处理完成后及时下载

常见问题

合并后原文件会被修改吗？

不会。系统会生成一份新的 PDF，原始文件不会被改写。

最多可以合并多少个文件？

当前一次最多选择 20 个 PDF，每个文件不超过 100MB。

如何调整合并顺序？

当前按上传选择的先后顺序合并。建议先给文件按 01、02、03 编号后再选择。
