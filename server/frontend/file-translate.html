文件翻译使用说明

翻译 TXT、Word 或 PDF 等文档内容，适合处理说明书、报告、邮件附件和一般办公资料。

使用步骤

  1. 选择需要翻译的文件
  2. 设置原语言和目标语言
  3. 选择输出格式并开始翻译
  4. 下载译文并核对重点内容

使用建议

  • 专业术语建议人工复核
  • 复杂排版可能会简化
  • 扫描 PDF 可先进行文字识别
  • 重要合同不应只依赖机器翻译

常见问题

为什么排版和原文不同？

翻译会改变文字长度，复杂表格、分栏和图片排版可能需要重新调整。

扫描件可以直接翻译吗？

扫描件需要先识别文字，清晰度会直接影响翻译结果。

上传的文件会长期保留吗？

不会。文件仅用于本次处理，完成后会按网站规则自动删除。
