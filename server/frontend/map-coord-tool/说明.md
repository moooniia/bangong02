## 🎨 设计信息

### 视觉风格

- 沿用主站 [bangong02.com](https://www.bangong02.com/) 的粉色品牌色（`#e94c88`）
- 字体：Playfair Display（展示）+ Noto Sans SC（正文）+ JetBrains Mono（坐标数据）
- 微经纬网格纹理作为 hero 区背景
- 三大坐标系用三色区分：BD-09 靛蓝 / GCJ-02 青 / WGS84 绿

### CSS 变量

```css
--pink:        #e94c88  /* 主色 */
--crs-bd:      #4f46e5  /* BD-09 坐标系 */
--crs-gcj:     #0891b2  /* GCJ-02 坐标系 */
--crs-wgs:     #059669  /* WGS84 坐标系 */
--font-mono:   'JetBrains Mono', 'SF Mono', monospace
```

### 主题切换

- 右上角月亮/太阳图标切换
- 默认跟随系统 `prefers-color-scheme`
- 地图随主题切换（深色时用 `style:'midnight'`，浅色时用 `style:'normal'`）

## ✨ 已实现功能

### ✅ 已完成

1. **地图显示** - 百度地图 WebGL 版（v1.0）
2. **点击选点** - 点击地图添加大头针，显示当前位置坐标
3. **坐标搜索** - 输入路名/地址搜索，点击结果跳转到该位置
4. **三系坐标转换**（自动联动）
   - BD-09（百度坐标）↔ GCJ-02（国测局/高德/腾讯）
   - BD-09 ↔ WGS84（GPS 原始）
   - GCJ-02 ↔ WGS84
5. **自动转换** - 输入坐标后自动计算并显示结果
6. **地图点击/搜索联动** - 一处操作，另一处自动同步
7. **暗色主题** - 页面 + 地图同步切换
8. **设计改造** - 沿用主站粉色品牌，加入三色坐标系区分、JetBrains Mono 坐标字体
9. **响应式布局** - 移动端 grid-2 折叠为单列
10. **城市坐标转换面板** - 含投影参数、七参数、手动输入

### ⏳ 待开发 / 待修复

1. **历史记录下拉提示** - 搜索自动保存到 localStorage 功能已加，但 datalist 触发不稳定，函数定义缺失问题待彻底修复
2. **地图卡片等高** - 右卡变高时左卡跟着拉高（CSS flex 已加，但百度地图 canvas 内部不自动重绘，需要在容器尺寸变化时手动调 `map.reset()` 或 `map.checkResize()`）
3. **批量转换** - 支持导入/导出 Excel
4. **其他地图底图** - 高德地图切换
