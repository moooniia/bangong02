旧导出表格中已经出现高风险现象：字段看起来被填满，但购方、销方、税号之间存在混淆风险。新版本必须优先暴露风险，而不是追求填满。

## 核心原则

- 不确定字段留空。
- 留空字段必须高亮。
- 高亮字段必须有原因。
- 原文件链接必须保留，方便人工点开原图/PDF 补录。
- Excel 导出中的高亮和原因不能丢失。

## 表格 UI

主表建议增加这些字段：

- `状态`
- `需人工确认`
- `异常原因`
- `原文件`
- `归档文件`

字段级高亮规则：

- `seller_name` 不确定：销售方单元格留空并高亮。
- `seller_tax` 不确定：销售方税号单元格留空并高亮。
- 购方和销方相同：清空销方，销售方和销售方税号高亮。
- 税号相同：清空销售方税号，高亮。
- OCR 只能识别到无归属的 `名称` 或 `税号`：不填入购方或销方，高亮对应缺失字段。

## 详情页 UI

详情页应显示：

- 原始图片/PDF 预览或打开入口。
- OCR 原文。
- 字段表单。
- 每个待确认字段旁显示原因。

用户人工填写后，应能清除对应字段的待确认状态。

## Excel 导出

导出时必须保留：

- 原文件链接。
- 归档文件链接。
- `需人工确认` 列。
- `异常原因` 列。
- 字段级高亮。

导出格式建议：

- 正常字段：普通样式。
- 需人工确认字段：醒目底色。
- 整行存在异常：状态列标记 `需人工确认`。
